# 🧩 Microsserviços

Afim de praticar a construção de microsserviços, construí alguns, demonstrados abaixo. A maioria deles emprega NodeJS, podendo usar APIs secundárias, construídas por mim ou externas, em Express, Python ou PHP.

| Nome               | Descrição                                                                                                                                                                                    | Ações                                                                                    |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| `logs-service`     | Microsserviço desenvolvido em Node.js com Express para captação, validação e persistência estruturada de logs do sistema para a prática de desenvolvimento de aplicações com microsserviços. | [CÓDIGO FONTE](https://github.com/andrewnationdev/code-snippets/tree/main/microservices) |
| `products-service` | Microsserviço RESTful desenvolvido em Node.js com Express para a gestão de produtos, utilizando persistência assíncrona baseada em arquivos JSON (`fs/promises`).                            | [CÓDIGO FONTE](https://github.com/andrewnationdev/code-snippets/tree/main/microservices) |
| `auth-service`     | Microsserviço simples de autenticação desenvolvido em Node.js e Express, utilizado para validação de credenciais de usuário e emissão de tokens JWT (fictícios).                             | [CÓDIGO FONTE](https://github.com/andrewnationdev/code-snippets/tree/main/microservices) |
